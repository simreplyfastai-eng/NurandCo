Payment — Stripe Setup
CHECKING…
To activate online payments:
  1. Go to stripe.com and create an account
  2. Copy your Secret Key and Publishable Key from the Stripe dashboard
  3. Add both to Replit Secrets as STRIPE_SECRET_KEY and STRIPE_PUBLISHABLE_KEY
  4. In Stripe, go to Developers → Webhooks → Add endpoint
  5. Set the endpoint URL to: [your-site-url]/api/stripe/webhook
  6. Select event: payment_intent.succeeded
  7. Copy the Webhook Secret and add it as STRIPE_WEBHOOK_SECRET
  8. Restart the server — Stripe is now live. No code changes needed.
