3. DASHBOARD FIGURES — REAL DATA FROM SUPABASE
===============================================================

All dashboard figures must come from Supabase.
No hardcoded or dummy data anywhere.

Revenue this month:
  SUM(deposit_amount) FROM bookings WHERE 
  location_id = current AND 
  created_at >= start of current month AND
  status != 'cancelled'

Appointments this month:
  COUNT(*) FROM bookings WHERE 
  location_id = current AND
  booking_date >= start of current month AND
  status != 'cancelled'

Active clients:
  COUNT(DISTINCT client_email) FROM bookings WHERE
  location_id = current AND status != 'cancelled'

Avg spend:
  AVG(total_price) FROM bookings WHERE
  location_id = current AND status = 'confirmed'
  OR status = 'complete'

Revenue by treatment chart:
  GROUP BY treatment_name, SUM(total_price)
  WHERE location_id = current

Recent bookings list:
  ORDER BY created_at DESC LIMIT 10
  WHERE location_id = current

All figures must update automatically when new 
bookings come in — no manual refresh needed.
