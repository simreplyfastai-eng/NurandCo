CLIENT DEDUPLICATION
━━━━━━━━━━━━━━━━━━━━━━━━
When a booking comes in from the main website:
1. Check if a client with the same email already 
   exists in the clients DB
2. If yes: add the booking to their existing 
   profile — do not create a new client entry
3. If no: create a new client profile with their 
   name and email, then attach the booking
4. This applies to both website bookings and 
   portal-created bookings
5. All client matching is done by email address 
   as the unique identifier — not name
6. All client data saves to Replit DB cloud — 
   not localStorage
