Fix all date and time handling across the entire codebase 
to use UK GMT/BST time correctly.

THE PROBLEM:
The server runs on UTC. The UK is:
- GMT (UTC+0) from last Sunday of October → last Sunday of March
- BST (UTC+1) from last Sunday of March → last Sunday of October

Dates created with new Date("2026-04-17") are parsed as 
UTC midnight which rolls back to the previous day when 
displayed in UK local time. All dates and times must 
display in UK local time always.

SOLUTION — use the Europe/London timezone everywhere:

1. SERVER-SIDE DATE HANDLING
Install the date-fns-tz package:
npm install date-fns-tz

Use this timezone constant everywhere:
const TIMEZONE = 'Europe/London'

Import and use these helpers everywhere dates are handled:
import { formatInTimeZone, toZonedTime, fromZonedTime } 
from 'date-fns-tz'
import { format } from 'date-fns'

NEVER use:
new Date("2026-04-17") — parsed as UTC, wrong
date.toUTCString()
date.getUTCDate() / getUTCMonth() / getUTCFullYear()
date.toISOString() for display purposes

ALWAYS use for display:
formatInTimeZone(date, 'Europe/London', 'EEEE d MMMM yyyy')
// outputs: "Friday 17 April 2026"

formatInTimeZone(date, 'Europe/London', 'HH:mm')
// outputs: "14:30"

2. PARSING DATES FROM CALENDAR
When user selects a date string "2026-04-17" from 
the calendar, parse it as UK local midnight:

function parseUKDate(dateStr) {
  // Parse as local UK midnight using date-fns-tz
  const [year, month, day] = dateStr.split('-').map(Number)
  // Create date at midnight in Europe/London timezone
  return fromZonedTime(
    new Date(year, month - 1, day, 0, 0, 0), 
    'Europe/London'
  )
}

9. .ICS CALENDAR FILE
For .ics files, DTSTART and DTEND must be in 
local UK time with no Z suffix:
Format: YYYYMMDDTHHMMSS (no Z = local time)

function formatICSDate(date) {
  return formatInTimeZone(date, 'Europe/London', 
    "yyyyMMdd'T'HHmmss")
  // outputs: 20260417T143000
  // NO Z at the end — Z means UTC which is wrong
}

Also add TZID to the .ics file:
DTSTART;TZID=Europe/London:20260417T143000
DTEND;TZID=Europe/London:20260417T151500
