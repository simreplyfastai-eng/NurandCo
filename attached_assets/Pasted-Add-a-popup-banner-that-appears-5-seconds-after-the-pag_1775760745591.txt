Use this JS function for getNextAvailableSlot():

Working hours:
Tuesday:   10:00 — 19:00  (last slot 18:00)
Wednesday: 10:00 — 19:00  (last slot 18:00)
Thursday:  10:00 — 19:00  (last slot 18:00)
Friday:    09:00 — 16:00  (last slot 15:00)
Saturday:  09:00 — 14:00  (last slot 13:00)
Sunday & Monday: closed

Logic:
1. Get current date + time
2. Loop forward from today through next 7 days
3. Skip Sunday (0) and Monday (1)
4. If today is a working day and current time is 
   before last slot — find next 30 min slot from now
   and return "Today at HH:MM"
5. If today is working day but past last slot —
   move to next working day, return 
   "Tomorrow from HH:MM" or "[Day] from HH:MM"
6. If today is closed — find next working day,
   return "Tomorrow from HH:MM" or "[Day] from HH:MM"

Opening time format:
Tue/Wed/Thu → "from 10:00"
Fri → "from 09:00"
Sat → "from 09:00"
