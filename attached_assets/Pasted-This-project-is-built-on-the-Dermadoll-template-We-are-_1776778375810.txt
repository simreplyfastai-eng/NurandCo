STEP 1 — INSTALL AND CONFIGURE SUPABASE CLIENT
===============================================================

Install the Supabase JS client:
  npm install @supabase/supabase-js

Create a new file: server/supabase.js

Content:
  import { createClient } from '@supabase/supabase-js';

  const supabaseUrl = process.env.SUPABASE_URL;
  const supabaseAnonKey = process.env.SUPABASE_ANON_KEY;
  const supabaseServiceKey = process.env.SUPABASE_SERVICE_KEY;

  export const supabase = createClient(
    supabaseUrl, supabaseAnonKey
  );

  export const supabaseAdmin = createClient(
    supabaseUrl, supabaseServiceKey,
    { auth: { autoRefreshToken: false, persistSession: false } }
  );

Test the connection immediately:
  const { data, error } = await supabaseAdmin
    .from('locations').select('*');
  console.log('Supabase connected:', data, error);

If error — fix before continuing.

STEP 3 — REPLACE ALL DATABASE CALLS WITH SUPABASE
===============================================================

Find every place in the codebase that reads or 
writes booking data. Replace ALL of them with 
Supabase queries.

CRITICAL: Every single Supabase query MUST include 
a location_id filter. No exceptions.

PATTERN TO FOLLOW FOR ALL QUERIES:

GET BOOKINGS:
  const { data, error } = await supabaseAdmin
    .from('bookings')
    .select('*, treatments(name, duration_minutes)')
    .eq('location_id', locationId)
    .eq('booking_date', date)
    .order('time_slot', { ascending: true });

CREATE BOOKING:
  const { data, error } = await supabaseAdmin
    .from('bookings')
    .insert({
      location_id: locationId,
      treatment_id: treatmentId,
      client_name: name,
      client_email: email,
      client_phone: phone,
      booking_date: date,
      time_slot: time,
      status: 'pending',
      deposit_amount: depositAmount,
      total_amount: totalAmount
    })
    .select()
    .single();

UPDATE BOOKING STATUS:
  await supabaseAdmin
    .from('bookings')
    .update({ status: newStatus })
    .eq('id', bookingId)
    .eq('location_id', locationId);

GET TREATMENTS:
  const { data } = await supabaseAdmin
    .from('treatments')
    .select('*')
    .eq('location_id', locationId)
    .eq('active', true)
    .order('name');

GET AVAILABILITY:
  const { data } = await supabaseAdmin
    .from('availability_settings')
    .select('*')
    .eq('location_id', locationId)
    .order('day_of_week');

GET BLOCKED DATES:
  const { data } = await supabaseAdmin
    .from('blocked_dates')
    .select('date, reason')
    .eq('location_id', locationId);

BLOCK A DATE:
  await supabaseAdmin
    .from('blocked_dates')
    .insert({ location_id: locationId, date: dateStr, reason })
    .onConflict('location_id, date')
    .ignore();

UNBLOCK A DATE:
  await supabaseAdmin
    .from('blocked_dates')
    .delete()
    .eq('location_id', locationId)
    .eq('date', dateStr);

CHECK SLOT AVAILABILITY:
  First check if date is blocked:
  const { data: blocked } = await supabaseAdmin
    .from('blocked_dates')
    .select('id')
    .eq('location_id', locationId)
    .eq('date', date)
    .single();
  if (blocked) return { available: false, reason: 'blocked' };

  Then check existing bookings for that slot:
  const { data: existing } = await supabaseAdmin
    .from('bookings')
    .select('id')
    .eq('location_id', locationId)
    .eq('booking_date', date)
    .eq('time_slot', timeSlot)
    .in('status', ['pending', 'confirmed']);
  if (existing?.length) return { available: false, reason: 'booked' };
