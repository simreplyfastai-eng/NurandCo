URGENT — Videos on the site show play buttons 
and don't autoplay. Fix this completely.

Read every component that renders a <video> 
tag — the results/transformations section, 
hero section, any video gallery.

CONFIRMED FROM INSPECTION:
  All video elements have correct attributes:
    autoPlay={true} muted={true} loop={true} 
    playsInline={true} controls={false}
  
  BUT all videos are paused on load.
  Calling .play() manually works fine.
  
  So the issue is: the .play() promise is 
  not being called after the component mounts
  AND there is a visible play button showing.

FIX 1 — Force play via useEffect/ref:

Every video component must use a ref and 
call .play() after mount:

  import { useEffect, useRef } from 'react'
  
  function VideoPlayer({ src }) {
    const ref = useRef(null)
    
    useEffect(() => {
      const v = ref.current
      if (!v) return
      v.muted = true  // must set muted via JS too
      v.play().catch(() => {}) // catch silently
    }, [src])
    
    return (
      <video
        ref={ref}
        src={src}
        autoPlay
        muted
        loop
        playsInline
        preload="auto"
        style={{ width:'100%', height:'100%', 
                 objectFit:'cover' }}
      />
    )
  }

Apply this pattern to EVERY video element 
on the site — results videos, hero video, 
any transformation videos.

FIX 4 — Intersection Observer for off-screen 
videos (performance + autoplay):

For videos that are not in the hero 
(results gallery etc), use an intersection 
observer to play when visible and pause 
when not:

  useEffect(() => {
    const v = ref.current
    if (!v) return
    const obs = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) {
          v.muted = true
          v.play().catch(()=>{})
        } else {
          v.pause()
        }
      },
      { threshold: 0.3 }
    )
    obs.observe(v)
    return () => obs.disconnect()
  }, [src])

This is especially important on mobile where 
multiple autoplaying videos can cause issues.
