1. STRIPE PUBLISHABLE KEY IN FRONTEND
━━━━━━━━━━━━━━━━━━━━━━━━
The frontend (index.html) needs the Stripe 
publishable key to load Stripe.js.

Create a new endpoint:
GET /api/config/stripe
Returns: { publishableKey: process.env.STRIPE_PUBLISHABLE_KEY }

In index.html, on page load fetch this 
endpoint and store the key:
const { publishableKey } = await fetch(
  '/api/config/stripe'
).then(r => r.json())
const stripe = Stripe(publishableKey)

Never hardcode the publishable key in 
the frontend HTML or JS.
If STRIPE_PUBLISHABLE_KEY is not set yet, 
the endpoint returns { publishableKey: null }
and the booking form shows:
"Online booking is temporarily unavailable. 
Please contact us on Instagram or WhatsApp 
to book."
