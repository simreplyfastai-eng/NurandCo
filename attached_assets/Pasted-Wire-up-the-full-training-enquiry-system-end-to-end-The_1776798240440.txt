PART 1 — SUPABASE TABLE
===============================================================

Run this in Supabase to create the enquiries table:

CREATE TABLE IF NOT EXISTS enquiries (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  location_id UUID REFERENCES locations(id),
  course_name TEXT NOT NULL,
  name TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT NOT NULL,
  experience_level TEXT,
  message TEXT,
  status TEXT DEFAULT 'new' 
    CHECK (status IN ('new','contacted','enrolled','closed')),
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE enquiries ENABLE ROW LEVEL SECURITY;

CREATE POLICY "enquiries_public_insert" 
  ON enquiries FOR INSERT TO anon WITH CHECK (true);
CREATE POLICY "enquiries_service_all" 
  ON enquiries FOR ALL TO service_role USING (true);

GRANT INSERT ON enquiries TO anon;
GRANT ALL ON enquiries TO service_role;

CREATE INDEX IF NOT EXISTS idx_enquiries_location 
  ON enquiries(location_id);
CREATE INDEX IF NOT EXISTS idx_enquiries_status 
  ON enquiries(status);

PART 3 — ENQUIRY API ENDPOINT
===============================================================

POST /api/enquiries
Public — no auth required

Validate:
  name: required, min 2 chars
  email: required, valid email format
  phone: required, min 7 chars
  course_name: required

Resolve location_id from course_name:
  'Essex Masterclass' → hornchurch location_id
  'London Masterclass' → marylebone location_id

Insert into Supabase enquiries table:
  {
    location_id,
    course_name,
    name: body.name.trim(),
    email: body.email.toLowerCase().trim(),
    phone: body.phone.trim(),
    experience_level: body.experience_level || null,
    message: body.message || null,
    status: 'new'
  }

If RESEND_API_KEY is set, send two emails:
  1. Admin alert to info@starrbeautyy.co.uk
  2. Auto-reply to the enquirer

Return: { success: true }
On error: { error: 'Failed to submit enquiry' }

GET /api/enquiries
Protected — requires JWT + X-Location-Id header
Returns all enquiries for that location
Ordered by created_at DESC

PUT /api/enquiries/:id
Protected — requires JWT
Body: { status, notes }
Updates enquiry status and/or notes
