9. RATE LIMITING ON BOOKING ENDPOINT
━━━━━━━━━━━━━━━━━━━━━━━━
POST /api/bookings is publicly accessible 
with no protection. A bot could spam 
hundreds of fake bookings.

Fix: add rate limiting to POST /api/bookings:
- Maximum 3 booking attempts per IP 
  address per 10 minutes
- On limit exceeded: return HTTP 429 with:
  "Too many booking attempts. 
  Please try again in a few minutes."
- Use express-rate-limit package:
  npm install express-rate-limit
- Apply only to POST /api/bookings and 
  POST /api/auth/login
- Do not apply to GET endpoints
