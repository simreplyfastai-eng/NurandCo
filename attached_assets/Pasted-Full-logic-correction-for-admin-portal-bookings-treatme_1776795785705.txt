FIX 4 — BOOKING VALIDATION (NO DOUBLE BOOKINGS)
===============================================================

When a booking is created (customer or admin):

STEP 1 — Check slot is available:
  Query Supabase:
  SELECT COUNT(*) FROM bookings
  WHERE location_id = [locationId]
  AND booking_date = [date]
  AND booking_time = [time]
  AND status NOT IN ('cancelled')
  
  If count > 0 → return 409 Conflict:
    { error: 'This slot is already booked' }

STEP 2 — Check date is not blocked:
  SELECT COUNT(*) FROM blocked_dates
  WHERE location_id = [locationId]
  AND date = [date]
  
  If count > 0 → return 409:
    { error: 'This date is not available' }

STEP 3 — Check location is open on this day:
  Get day_of_week from the booking_date
  Query availability_settings:
  SELECT is_open FROM availability_settings
  WHERE location_id = [locationId]
  AND day_of_week = [dayOfWeek]
  
  If is_open = false → return 409:
    { error: 'Clinic is closed on this day' }

STEP 4 — Check time is within working hours:
  Get open_time and close_time from availability_settings
  If booking_time < open_time OR 
     booking_time >= close_time → return 409:
    { error: 'Outside working hours' }

STEP 5 — Check for blocked time slots:
  SELECT COUNT(*) FROM blocked_slots
  WHERE location_id = [locationId]
  AND (
    (day_of_week = [dayOfWeek] OR all_days = true)
    AND start_time <= [bookingTime]
    AND end_time > [bookingTime]
  )
  
  If count > 0 → return 409:
    { error: 'This time slot is blocked' }

ALL 5 checks must pass before booking is created.
Apply to both POST /api/bookings AND the Stripe 
webhook booking creation.

FIX 5 — AVAILABLE SLOTS ENDPOINT
===============================================================

GET /api/availability/slots?location=[id]&date=[date]

This endpoint powers the customer booking calendar.
It must return only genuinely available slots.

Algorithm:
  1. Get availability_settings for this location + day
     → If closed: return { available: false, slots: [] }
  
  2. Generate 30-min slots from open_time to close_time
     e.g. 10:00, 10:30, 11:00... 18:30
  
  3. Remove blocked_slots for this location+day
  
  4. Remove slots that have existing bookings
     (status NOT IN 'cancelled')
  
  5. Remove past slots if date is today
  
  6. Return: { available: true, slots: ['10:00','10:30'...] }

This must be called by the booking widget before 
showing the time picker to the customer.
