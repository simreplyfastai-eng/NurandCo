BULLETPROOF 1 — WEBHOOK RETRY SAFETY

The webhook can fire before the forms page 
loads. Add a retry mechanism:

In GET /api/bookings/by-session/:sessionId:
  Let retries = 0
  While retries < 5:
    Check Supabase for booking with 
    stripe_session_id = sessionId
    If found → return it
    If not found → wait 1 second, retry
    retries++
  If still not found after 5 retries:
    Return 404 with message:
    "Booking is being processed, 
     please refresh in a few seconds"

This handles the race condition where 
Stripe redirects faster than the webhook 
processes.

BULLETPROOF 2 — IDEMPOTENT WEBHOOK

The webhook can fire MORE THAN ONCE for 
the same payment (Stripe retries on failure).

Add a duplicate check at the TOP of the 
webhook handler:

  const existingBooking = await supabaseAdmin
    .from('bookings')
    .select('id')
    .eq('stripe_session_id', session.id)
    .single()
  
  if (existingBooking.data) {
    console.log('Webhook already processed:', 
      session.id)
    return res.json({ received: true })
  }
  
  // Only proceed if not already processed

This prevents double-bookings from 
webhook retries.

BULLETPROOF 3 — WEBHOOK SIGNATURE 
VERIFICATION

Always verify the Stripe webhook signature:

  const sig = req.headers['stripe-signature']
  let event
  
  try {
    event = stripe.webhooks.constructEvent(
      req.rawBody,
      sig,
      process.env.STRIPE_WEBHOOK_SECRET
    )
  } catch(err) {
    console.error('Webhook sig error:', err)
    return res.status(400).send('Bad signature')
  }

This prevents fake webhook calls from 
anyone who knows your URL.

IMPORTANT: The webhook route must use 
express.raw() not express.json():
  app.post('/api/stripe/webhook', 
    express.raw({type: 'application/json'}),
    webhookHandler
  )

BULLETPROOF 4 — WEBHOOK ERROR LOGGING

Wrap the entire webhook handler in 
try/catch and log every error:

  try {
    // all booking creation code here
    console.log('Webhook success:', session.id)
    return res.json({ received: true })
  } catch(err) {
    console.error('WEBHOOK FAILED:', {
      sessionId: session.id,
      error: err.message,
      stack: err.stack
    })
    // Still return 200 to Stripe so it 
    // doesn't keep retrying
    return res.status(200).json({ 
      received: true, 
      warning: 'Processing error logged' 
    })
  }
