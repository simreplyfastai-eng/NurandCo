FIX 1 — VERIFY AND FIX POST /api/media/config
===============================================================

Find the POST /api/media/config endpoint.
Check if it actually writes to Supabase.

It MUST do this:

  app.post('/api/media/config', authMiddleware, 
    async (req, res) => {
      const { field, value } = req.body
      
      // Get current value from Supabase
      const { data: current } = await supabaseAdmin
        .from('portal_kv')
        .select('value')
        .eq('key', 'dd_media')
        .single()
      
      const existing = current?.value || {}
      const updated = { ...existing, [field]: value }
      
      // Write back to Supabase
      const { error } = await supabaseAdmin
        .from('portal_kv')
        .upsert(
          { key: 'dd_media', value: updated },
          { onConflict: 'key' }
        )
      
      if (error) {
        console.error('Media save error:', error)
        return res.status(500).json({ error: error.message })
      }
      
      return res.json({ success: true, field, value })
    }
  )

If this endpoint doesn't exist — create it.
If it exists but uses filesystem or memory — 
replace it with the Supabase version above.
