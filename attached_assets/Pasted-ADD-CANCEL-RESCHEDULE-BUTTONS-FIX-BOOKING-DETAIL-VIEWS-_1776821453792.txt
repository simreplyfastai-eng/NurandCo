PART 5 — FIX CLIENTS TAB BOOKING HISTORY
===============================================================

When clicking a client name in the Clients 
tab, the profile must show their full 
booking history with for each booking:

  [Treatment Name]
  [Date — formatted "22 Apr 2026"]
  [Time — HH:MM]
  [Status badge]
  [Deposit paid]
  [...] action menu → Reschedule / Cancel

Currently the booking history either doesn't 
show or shows incomplete info.

Fix by fetching:
  SELECT b.*, t.name as treatment_name_joined
  FROM bookings b
  LEFT JOIN treatments t ON t.id = b.treatment_id
  WHERE b.client_email = clientEmail
  OR b.client_id = clientId
  ORDER BY b.booking_date DESC

Show each booking as a row with all 
the fields listed above.
