Fix the footer social section on mobile.
Read the CSS for .footer-social-block, 
.footer-social-headers and .footer-social-grid 
before making any changes.

EXACT PROBLEM (confirmed from live inspection):
  .footer-social-headers: grid, 2 cols, 131px each
  .footer-social-grid: grid, 2 cols, 147px each, 
    gap 32px
  
  On a 375px phone this creates two cramped columns.
  @StarrAestheticss gets cut off, pills overflow.

WHAT TO DO:

Add a media query at max-width 640px that changes
ONLY these three classes:

@media (max-width: 640px) {

  .footer-social-block {
    display: flex;
    flex-direction: column;
    align-items: center;
    gap: 0;
    width: 100%;
  }

  .footer-social-headers {
    display: flex;
    flex-direction: column;
    align-items: center;
    width: 100%;
    gap: 0;
  }
  
  /* Show only Instagram label on mobile 
     since we stack vertically */
  .footer-social-headers span:first-child {
    display: block;
    text-align: center;
    margin-bottom: 12px;
  }
  
  .footer-social-headers span:last-child {
    display: none;
  }

  .footer-social-grid {
    display: flex;
    flex-direction: column;
    align-items: center;
    width: 100%;
    gap: 0;
  }
}

pills together in one grid (Instagram row 1,

Read how the pills are ordered inside

  INSTAGRAM label
