AUDIT 5 — SESSION ISOLATION
===============================================================

User sessions (cookies/JWT tokens) must 
be completely separate between projects. 
A user logged into Dermadoll's portal 
cannot accidentally access Niamh's portal.

Check the session configuration:

// In server.js find where sessions/JWT are configured
// The JWT_SECRET must be unique per project
// The cookie name should be unique per project

// Check session cookie name:
grep -n "session\|cookie\|jwt" server.js | head -20

Ensure the cookie name is unique:
// BAD — generic name shared across projects:
app.use(session({ name: 'sessionId', ... }))

// GOOD — unique per client:
app.use(session({ name: 'fbn_session', ... }))

Update the session cookie name to 'fbn_session'
so it cannot conflict with Dermadoll's cookies
even if both are open in the same browser.
